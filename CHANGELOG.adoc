= Changelog

Functional changes for `dev-centr/stack-advisor` (definitions + Stack Advisor web app).

== 2026-08-25 — View transitions on level changes

* Focus, selection, path insert/remove, and reset wrap DOM updates in the View Transitions API.
* Level column, context panel, and path strip use named transitions with a short crossfade.
* Respects `prefers-reduced-motion`.
* See link:changelog-details/2026-08-25 - view-transitions.adoc[Detailed changelog].

== 2026-08-25 — Unified filter path + host icons

* One filter flow from the sample path — no Guided / Build mode split; clear levels with ×; **Reset to sample**.
* Numbered crumbs, sans font, green selection lights; no auto-forward on pick.
* Host options use licensed SVG marks (Simple Icons / Lucide); WSL is Windows + Linux.
* Compound path strip with vertical dividers between segments; **+** between segments inserts a missing level; circular **+** outside appends.
* See link:changelog-details/2026-08-25 - unified-filter-path.adoc[Detailed changelog].

== 2026-08-25 — Stack Advisor product + repo rename

* Public product name is **Stack Advisor** (stack decision outcome; browse and advice are modes).
* GitHub repository renamed `toolchain-advisor` → `stack-advisor`.
* Packages: `@dev-centr/stack-advisor`, `@dev-centr/stack-advisor-core`.
* Standalone Pages base/URL: `https://dev-centr.github.io/stack-advisor/`.
* See link:changelog-details/2026-08-25 - stack-advisor-rename.adoc[Detailed changelog].

== 2026-08-25 — Toolchain Browser web app + filter fix

* Extracted the interactive UI into `web/` (standalone Vite/Solid SPA + package import for devcentr.org).
* Modes: **Guided path** (preload) and **Build filters** (DIY gated levels).
* Focus one level at a time with a breadcrumb strip; small option sets use an icon grid.
* Core: empty selections are unset for ranking; helpers `emptySelections`, `filterOptions`, `prefersIconGrid`.
* Standalone deploy: GitHub Pages workflow (historically under the prior repo name).
* See link:changelog-details/2026-08-25 - toolchain-browser-web.adoc[Detailed changelog].
